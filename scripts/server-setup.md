# Конфигурация виртуальной машины devops-vm

## 1. Параметры машины
- Объем оперативной памяти: 2048 МБ
- Количество ядер процессора: 2
- Объем дискового накопителя: 25 ГБ

## 2. Сетевые интерфейсы
- Адаптер 1: NAT (полученный адрес: 10.0.2.15), назначение: доступ в интернет.
- Адаптер 2: Host-only (полученный адрес: 192.168.56.101), назначение: доступ с хостовой системы.

## 3. Правило проброса портов
- Порт хостовой системы: 2222
- Порт гостевой системы: 2222

## 4. Учётные записи
- `student`: член группы `sudo`, аутентификация по паролю (резервная).
- `devops`: член группы `sudo`, аутентификация по ключу.

## 5. Служба SSH
- Порт: 2222
- Измененные директивы (файл `/etc/ssh/sshd_config.d/99-hardening.conf`):
  - PermitRootLogin no
  - PasswordAuthentication no
  - MaxAuthTries 3
  - AllowUsers devops
- Файл конфигурации: `/etc/ssh/sshd_config.d/99-hardening.conf`

## 6. Правила межсетевого экрана
- Политика по умолчанию: deny incoming, allow outgoing
- Разрешенные порты:
  - 2222/tcp (SSH rate-limited)
  - 80/tcp (HTTP)
  - 443/tcp (HTTPS)

## 7. Снимки состояния
- `01-clean-install` — чистая установка Ubuntu Server.
- `02-keys-configured` — настроена ключевая аутентификация.
- `03-ssh-hardened` — усилена защита SSH.
